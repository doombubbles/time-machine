# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

- Fixed for BTD6 v56

## [1.1.6] - 2026-04-27

- There are now configurable hotkeys for stepping forwards and backwards within the current match's saved rounds (default Alt+LeftArrow / Alt+RightArrow)
- Fixed Challenge Editor saves being cleared too aggressively

## [1.1.6] - 2026-04-27

- There are now configurable hotkeys for stepping forwards and backwards within the current match's saved rounds (default Alt+LeftArrow / Alt+RightArrow)
- Fixed Challenge Editor saves being cleared too aggressively

## [1.1.5] - 2025-12-08

- Improved Time Machine save loading capability for Frontier Legends matches
  - Traits, Skins, and Stamina states now get correctly saved and loaded
  - Bosses get correctly saved, apart from Diamondback as NK hasn't set that up properly yet

## [1.1.4] - 2025-12-03

- Fixed for v52

## [1.1.3] - 2025-02-10

- Fixed bugged interactions with Artifacts and rogue party when restoring saves within Rogue Legends
- Timelines UI shows up on Rogue defeat screen (but at that point you will have lost the life already)

## [1.1.2] - 2024-10-09

- Fixed compression issue with newly created saves

## [1.1.1] - 2024-10-09

- Fixed for BTD6 v45

## [1.1.0] - 2024-08-16

- Now loads saves faster
- Fixed to also work for Daily Challenges / Challenge Editor
- Fixed to also work on Custom Maps from the Content Browser / Map Editor

## [1.0.7] - 2024-06-02

- Fixed for BTD6 v43

## [1.0.6] - 2024-04-14

- Fixed for BTD6 v42
- Fixed for Boss Event saves and Boss Challenge saves

## [1.0.5] - 2023-12-10

- Fixed for BTD6 v40

## [1.0.4] - 2023-11-08

- Fixed saves being able to ever be deleted while you were still in a game, in this case a Boss match

## [1.0.3] - 2023-11-01

- Fixed for BTD6 v39

## [1.0.2] - 2023-06-09

- Fixed for BTD6 v37

## [1.0.1] - 2023-04-04

- Fixed for BTD6 v36

## [1.0.0] - 2023-03-25

- Initial Release
